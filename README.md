## 🪖 ──¤﹝ نـبـذة عـن الـمـكـتـبـة ↶ 🕸️﹞

**GOJO BOT** هي مكتبة Node.js متطورة مبنية على بايليز معدل لبناء بوتات واتساب احترافية.  
مصممة للمطورين لي باغيين قوة + سرعة + ذكاء اصطناعي في بوت واحد.

> *"القوة الحقيقية في الكود النظيف" - YONO DEV 🥷🏻*

## ⚡ ──¤﹝ الـمـمـيـزات ↶ 🚀﹞

| الميزة | الوصف |
| --- | --- |
| **🤖 الذكاء الاصطناعي** | دمج AI Chat, توليد صور, تلوين, ترجمة تلقائية |
| **⚡ Baileys Yono** | نسخة معدلة ومحسنة من بايليز للاستقرار والسرعة |
| **🎨 توليد الصور** | Flux AI, Pollinations, DeepImg بجودة 1024x1024 |
| **🔧 بلاجينات جاهزة** | +50 بلاجين جاهز: ترند, ايموجي, تحميل, العاب |
| **🛡️ الحماية** | نظام انتي سبام, انتي لينك, طرد تلقائي |
| **📊 خفيف وسريع** | استهلاك رام قليل واداء عالي |
| **🌍 متعدد اللغات** | دعم عربي كامل + انجليزي |
| **📦 سهل التنصيب** | سطرين وتخدم البوت ديالك |
